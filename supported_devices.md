# Supported Devices

- Tested on Raspberry Pi 5 with Grove sensors/actuators, but should work with generic kits as well as long as pins match

## I2C

### Input

- Grove 3-Axis Accelerometer
- Grove Gesture Detector
- Grove Barometer Sensor

### Output

- Grove LCD (16x2)
- Grove LED Matrix

## Digital

### Input

- Digital Input Devices (generic)

  - Grove Line Finder
  - Grove Tilt Switch
  - Grove PIR Motion Sensor
  - Grove Flame Sensor
  - Grove Button
  - Grove Switch (SPDT)
  - Grove Touch Sensor
  - etc..

- Grove Encoder
- Grove Ultrasonic Ranger

### Output

- Digital Output Devices (generic)

  - Grove Vibration Motor
  - Grove LED
  - etc..

- Grove Buzzer
- Grove Chainable RGB LED

## Analog

- Analog Input Devices (generic)

  - Grove Gas Sensor (MQ2)
  - Grove Loudness Sensor
  - Grove Light Sensor
  - Grove GSR (galvanic skin response) Sensor
  - etc..

- Grove Base Hat (required for ADC conversion)

## Serial —— ONLY ON RASPI 4 DUE TO MISSING PI4J PROVIDER FOR RASPI 5

- Grove GPS (Air530)
